# 양식별 입력 템플릿

> 4가지 양식 각각에 대해 아래를 채우면, 마스터를 그 양식에 맞춰 변주한다.
> 양식 1개당 폴더 하나(`양식N_회사명/`) → 그 안에 `00_입력.md`(이 템플릿) · `초안.md` · `최종.md`.
> 채우는 기준은 `../지침.md` ① 전략(§1·§11), 사실 경계는 `../지침.md` ③ 정직성. 소재는 `../경험자산.md`.

## 입력 항목 (회사별로 채우기)

```
[양식 식별]
- 양식 번호 / 회사명 / 지원 직무 / 마감일:

[양식 구조 — 가장 중요]
- 문항 목록 (번호 + 질문 그대로):
   1)  2)  3)  4)
- 문항별 글자 수 / 제한:
- 기타 제약: (자유양식/표/PDF/온라인 폼)

[회사 분석]
- 주요 서비스 / 최근 사업 방향 / 직무 업무 / 요구·우대 역량 / 인재상 / 내 경험 연결점:

[변주 지시]
- 강조할 핵심 역량 3개 / 쓸 경험 3개(문항별) / 절대 안 쓸 경험:
- 베이스 마스터: 버전 A(4문항) / 버전 B(연결본) 중 택1
- 추가 기준 (junsang 직접):
```

## 처리 흐름

1. 입력 채우기 (회사 분석은 모르면 채용공고·뉴스 리서치로 보강).
2. `../마스터자소서.md`에서 베이스를 가져와 문항·글자수에 맞게 변주.
3. 커스터마이저 5조건 적용 ('저는' 금지·뻔한 표현 금지·회사 언어).
4. `../지침.md` ③ 정직성으로 검수 (날조 0).
5. `../지침.md` ① 전략 §2 평가 기준 6개로 셀프 비판 → 재작성.
6. `최종.md` 확정.
```
