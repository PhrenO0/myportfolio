# 자기소개서 전략 (마스터 지침)

> 출처: Notion `자기소개서 전략`. 자소서는 글쓰기 과제가 아니라 **나라는 사람을 채용자 관점에서 해석시키는 기획서**다.
> 핵심: **좋은 자소서는 '멋진 문장'이 아니라, 내가 어떤 문제를 어떤 방식으로 해결해온 사람인지 납득시키는 글이다.**

## 1. 쓰기 전에 먼저 정할 것 (5가지)

1. 지원 직무
2. 지원 산업/회사
3. 보여주고 싶은 핵심 역량
4. 그 역량을 증명할 경험
5. 회사가 나를 뽑아야 하는 이유

경험이 여러 방향(미디어·도시계획·AI·영상·Azure·창업)으로 흩어져 있으므로, **중심 문장은 하나여야** 한다.

> 예) **저는 사용자 경험과 데이터, AI 기술을 연결해 실제 문제를 제품 구조로 바꾸는 서비스기획자입니다.**

이 중심 문장을 먼저 잡고 모든 경험을 거기에 맞게 재배열한다.

## 2. 평가 기준 (검증용 — 칭찬 말고 비판하게)

1. 직무 적합성이 명확한가
2. 경험이 구체적인가
3. 내가 한 행동이 보이는가
4. 성과나 배운 점이 있는가
5. 문장이 추상적이거나 GPT스럽지 않은가
6. 뽑고 싶은 사람처럼 보이는가

## 3. 기본 문단 구조

```
1. 주장      → 저는 ~한 사람입니다.
2. 근거 경험  → 이 역량은 ~경험에서 구체화되었습니다.
3. 내 행동    → 당시 문제는 ~였고, 저는 ~를 했습니다.
4. 결과·배움  → 그 결과 ~를 얻었습니다.
5. 직무 연결  → 이 경험으로 ~직무에서 ~에 기여하고 싶습니다.
```

중요한 건 **문장력보다 논리의 흐름.**

## 4. 작성 규칙

- **규칙 1.** "관심이 있습니다"만 쓰지 말기 → 경험으로 생긴 **관점**을 써라.
- **규칙 2.** "많이 배웠습니다" 금지 → 배운 점은 **구체적으로.**
- **규칙 3.** "다양한 경험을 했습니다" 금지 → 다양한 경험을 **하나의 방향**으로 묶어라.
- **규칙 4.** 프로젝트 이름만 나열 금지 → **내가 어떤 문제를 어떻게 구조화했는지**가 핵심.
- **규칙 5.** 성과 수치가 없으면 **구조(문제정의·판단·설계·역할·개선)로** 보여줘라.

## 5. 문항별 구조 전략

- **지원동기**: 회사/직무가 다루는 문제 → 관심 계기 → 내 경험 연결 → 기여 방향. (회사 칭찬으로 시작 금지. **내 문제의식과 회사의 일이 만나는 지점**에서 시작.)
- **직무역량**: 역량 정의 → 발휘 경험 → 구체 행동 → 결과/배움 → 직무 적용.
- **협업경험**: 팀 상황 → 갈등/문제 → 내가 한 조율 → 결과 → 협업관. ("소통했습니다" 아니라 **서로 다른 역할을 어떻게 맞췄는지**.)
- **창의성/도전**: 기존 방식의 한계 → 새 접근 → 실행 → 어려움 → 결과. (A.INUS·AdGuard 추천)
- **입사 후 포부**: 방향성 → 초기에 할 일 → 중장기 가치. (거창하면 안 됨. 초기 3개월 행동 구체화.)

## 6. 작성 순서 (절대 완성본부터 쓰지 말 것)

```
1. 지원 직무 정하기
2. 채용공고 분석
3. 경험 재료표 만들기
4. 문항별 경험 매칭
5. 각 문항 핵심 주장 1문장
6. STAR 구조 정리
7. 초안 작성
8. 채용자 관점 비판 받기
9. 자연스럽게 재작성
10. 최종 사실 검수
```

> **정리 → 매칭 → 초안 → 비판 → 재작성.**

## 7. 절대 하면 안 되는 것

- 채용공고 없이 쓰기 / 경험 뭉뚱그리기 / 과장된 성과 / 너무 매끈한 문장 / 회사마다 같은 글 / AI 추상어 그대로 / 사실 확인 없이 기술명. → 상세: `정직성_규칙.md`

## 8. 포지셔닝 (직무별)

- **기본값**: AI와 콘텐츠, 공간/시장 맥락을 연결해 실제 사용자가 이해하고 행동할 수 있는 서비스 경험으로 바꾸는 기획자.
- **AI 서비스기획**: AI 기능을 사용자 문제와 서비스 흐름 안에 배치하는 기획자.
- **콘텐츠/브랜드 기획**: AI와 스토리텔링으로 브랜드 경험을 구체적 장면·메시지로 만드는 기획자.
- **프롭테크/공간**: 공간·시장 데이터를 사용자 의사결정에 연결하는 AI 서비스기획자.
- **창업/스타트업**: 현실 문제를 빠르게 구조화하고 AI로 MVP 검증하는 Product Builder.

## 9. 최종 규칙

```
1. 경험보다 관점이 중요하다.
2. 관점보다 근거가 중요하다.
3. 근거보다 직무 연결이 중요하다.
4. 문장은 화려하지 않아도 된다.
5. 내가 한 행동이 보여야 한다.
6. 회사가 뽑을 이유가 있어야 한다.
7. GPT는 초안 도구가 아니라 사고를 정리하는 도구다.
```

> **자소서를 맡기지 말고, 내 경험을 직무 언어로 번역하게 만들어라.**
