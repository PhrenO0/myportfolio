## 0. 딱 하나의 원칙 — "학기엔 조이고, 방학엔 푼다"

3-2를 **실제로 다녀야** 한다(부동산 6~7학점 + 본전공 = 풀 로드). 그래서 모든 스트림을 **항상 켜지 않는다.**
- **방학 = 출력 MAX** — 공모전·해커톤·채널 착수·인턴 프렙을 여기 몰기(시간이 있는 창).
- **학기 = 유지 모드** — 학업 안정권 + 채널 유지(주 1~2편) + 학회 1 + 근로. **신규 공모전·해커톤은 절제.**
- 이걸 어기면 학점도 채널도 학회도 **다 같이 무너진다.** 동시에 켜는 건 학기 2개·방학 3개까지.

## 3. 3-2 학기 '살 수 있는' 주간 템플릿

- **평일:** 수업 + **콘텐츠 근로 주 10~12h** + 학회 주 1회 모임. (이 3개가 학기의 뼈대)
- **주말:** 채널 촬영·편집 **반나절**(주 1~2편). 나머지는 회복.
- **시험기간(중간·기말 각 ~2주):** 채널 **주 1편으로 축소**, 학업 몰빵. (끊지는 않음)
- **격주 토요일(집행기):** 메타 소재 A/B 점검 30분 → CTR·CPC 기록.
- **매일:** '오늘의 단 하나'(neural-flow) — 과확장 금지, 나머지는 백로그.
- **에너지 규칙:** 학기 중 동시 가동 = **최대 2개(채널 + 학회).** 공모전·해커톤은 **방학·주말**에만 추가.
