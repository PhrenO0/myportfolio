# 양식별 입력 템플릿

> 4가지 양식 각각에 대해 아래 표를 채우면, 마스터본을 그 양식에 맞춰 변주한다.
> 양식 1개당 폴더 하나(`양식N_회사명/`)를 만들고 그 안에 `00_입력.md`(이 템플릿) + `초안.md` + `최종.md`를 둔다.
> 채우는 기준은 `../01_지침/자소서_전략.md` §1 / §11, 사실 경계는 `../01_지침/정직성_규칙.md`.

## 입력 항목 (회사별로 채우기)

```
[양식 식별]
- 양식 번호:            (예: 양식1)
- 회사명:
- 지원 직무:
- 마감일:

[양식 구조 — 가장 중요]
- 문항 목록 (번호 + 질문 그대로):
   1)
   2)
   3)
   4)
- 문항별 글자 수 / 제한:
   1)   자
   2)   자
   3)   자
   4)   자
- 기타 양식 제약: (자유양식/표 형식/PDF 업로드/온라인 폼 등)

[회사 분석]
- 회사 주요 서비스 / 최근 사업 방향:
- 직무 주요 업무:
- 요구·우대 역량:
- 인재상 / 핵심 가치:
- 내 경험과 연결되는 지점:

[변주 지시]
- 강조할 핵심 역량 3개:
- 쓸 경험 3개 (문항별):
- 절대 쓰지 않을 경험:
- 베이스 마스터: (v7 연결본 / 4문항 필살기 중 택1)
- 추가 기준 (junsang이 직접 추가):
```

## 처리 흐름

1. 위 입력을 채운다 (회사 분석은 모르면 Claude가 채용공고·뉴스 리서치로 보강).
2. 베이스 마스터(`../00_마스터/`)에서 문항을 가져와 글자 수·문항 구조에 맞게 변주.
3. `커스터마이저_프롬프트.md` 5개 조건 적용 ('저는' 금지·뻔한 표현 금지·회사 언어).
4. `정직성_규칙.md` 사실 경계로 검수 (날조 0).
5. `자소서_전략.md` §2 평가 기준 6개로 셀프 비판 → 재작성.
6. `최종.md` 확정.
```
