## 사용법 (1 마스터 → 4 양식)

1. 회사별로 `양식별_출력/_입력_템플릿.md`를 복사 → `양식별_출력/양식N_회사명/00_입력.md`에 문항·글자수·회사분석·추가기준 채우기.
2. 베이스 선택(버전 A/B) → 문항·글자수에 맞게 변주 + 커스터마이저 5조건.
3. `지침.md` ③ 정직성으로 검수(날조 0) → ① 전략 §2 평가기준 6개로 셀프 비판 → 재작성 → `최종.md`.

## 불변 원칙

- **경험·숫자 불변.** 회사 언어·문항 구조·글자수만 변주.
- **'저는' 시작 금지 · '귀사/지원하게 되었습니다/성장하고 싶습니다/많이 배웠습니다' 금지.**
- **날조 0**: 무신사 미수상 · A.INUS 팀수상 · E-Nudge 설계까지(9기 1차 1위=팀/프로젝트 결과, 단독 달성 과장 금지) · 기억의궁전=3D엔진/UI(GraphRAG=윤재) · Lynch/85%/방배치 금지. → `지침.md` ③
