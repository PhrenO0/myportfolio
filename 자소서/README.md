junsang(오준상)의 자기소개서 생산 파이프라인. **마스터 1개 → 회사별 양식에 맞춰 변주**하는 반복 구조.
포지셔닝: **CX형 AI 서비스기획자 (Experience-led Product Builder)** — '그로스 마케터'로 좁히지 말 것.

## 구조 (5개 문서)

| 파일 | 내용 |
|---|---|
| `README.md` | 개요·사용법·핸드오프·출처 (이 문서 = 단일 진입점) |
| `마스터자소서.md` | 버전 A(4문항·~1,200자·슬롯형) + 버전 B(연결본 v7·서사형) |
| `지침.md` | ① 전략(평가기준 6) ② 커스터마이저 프롬프트 ③ 정직성 규칙(날조 0) |
| `경험자산.md` | 경험 12종 + 수상·수료 5종 + 케이스 스터디(문제→설계→결과) |
| `양식별_출력/_입력_템플릿.md` | 양식 1개당 채울 입력 양식 (→ `양식N_회사명/` 폴더로 작업) |

## 사용법 (1 마스터 → 4 양식)

1. 회사별로 `양식별_출력/_입력_템플릿.md`를 복사 → `양식별_출력/양식N_회사명/00_입력.md`에 문항·글자수·회사분석·추가기준 채우기.
2. 베이스 선택(버전 A/B) → 문항·글자수에 맞게 변주 + 커스터마이저 5조건.
3. `지침.md` ③ 정직성으로 검수(날조 0) → ① 전략 §2 평가기준 6개로 셀프 비판 → 재작성 → `최종.md`.

## 불변 원칙

- **경험·숫자 불변.** 회사 언어·문항 구조·글자수만 변주.
- **'저는' 시작 금지 · '귀사/지원하게 되었습니다/성장하고 싶습니다/많이 배웠습니다' 금지.**
