# 자소서 파이프라인

junsang의 자기소개서 생산 파이프라인. **마스터 자소서 1개 → 회사별 양식에 맞춰 변주**하는 반복 구조.

포지셔닝: **CX형 AI 서비스기획자 (Experience-led Product Builder)**

## 디렉토리 구조

```
자소서/
├── README.md                  ← 이 문서 (파이프라인 개요)
├── SESSION-HANDOFF.md         ← 세션 인계 문서 (다음 세션은 이것부터 읽기)
├── 00_마스터/                  ← 모든 변주의 원본
│   ├── 마스터_v7_연결본.md       · ①853 ②1,258 ③931 ④799자, '연결 실' 서사
│   └── 마스터_4문항_필살기.md     · 4문항 ×~1,200자, [회사명] 슬롯형
├── 01_지침/                    ← 기존 문서 지침 (불변 규칙)
│   ├── 자소서_전략.md            · 평가기준 6개 · 작성규칙 · 문항별 전략
│   ├── 커스터마이저_프롬프트.md    · 회사별 변주 재사용 프롬프트
│   └── 정직성_규칙.md            · 날조 0 — 사실 경계 (절대 규칙)
├── 02_경험자산/
│   └── 경험자산.md              · 경험 10종 + 정량성과 + 문항별 소재 매핑
└── 03_양식별_출력/              ← 회사별 결과물
    ├── _입력_템플릿.md           · 양식 1개당 채울 입력 양식
    └── 양식N_회사명/             · (작업 시 생성) 00_입력 · 초안 · 최종
```

## 사용법 (1 마스터 → 4 양식)

1. **양식 입력**: 회사별로 `_입력_템플릿.md`를 복사해 `03_양식별_출력/양식N_회사명/00_입력.md`에 채운다 (문항·글자수·회사분석·추가기준).
2. **베이스 선택**: v7 연결본 / 4문항 필살기 중 하나를 base로.
3. **변주**: 문항·글자수에 맞게 마스터를 재구성 + 커스터마이저 5개 조건 적용.
4. **정직성 검수**: `정직성_규칙.md` 사실 경계로 점검 (날조 0).
5. **셀프 비판 → 재작성**: `자소서_전략.md` §2 평가 기준 6개로 검증.
6. **확정**: `최종.md` 저장.

## 불변 원칙

- **경험·숫자는 절대 안 바뀜.** 회사 언어·문항 구조·글자수만 변주.
- **'저는'으로 시작 금지 · '귀사/지원하게 되었습니다/성장하고 싶습니다' 금지.**
- **날조 0**: 무신사 미수상 · A.INUS 팀수상 · E-Nudge 설계까지 · GraphRAG=윤재. → `01_지침/정직성_규칙.md`
