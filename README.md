# 오준상 — Portfolio

> **AI로 직접 만드는 콘텐츠·서비스 기획자.**
> 복잡한 정보를, 사람이 이해하고 판단하고 *행동*할 수 있는 서비스 흐름으로 바꾼다.

중앙대학교 미디어커뮤니케이션학부(본전공) · 도시계획·부동산학부(복수전공).
영상으로 사람을 모아본 감각, 멀티에이전트·풀스택을 끝까지 출시하는 실행력, 사용자를 깊이 이해하는 리서치 — 셋을 한 몸에 가진 빌더형 기획자.

---

## 북극성 (3~5년)
**소비자·콘텐츠 AI 프로덕트 기획자.**
AI × 콘텐츠/영상 × 사용자 이해, 세 자산이 동시에 레버리지되는 지점에서 일한다.
→ 모든 선택의 기준: *"이게 그 지점으로 가는 사다리인가."*

## 핵심 가치 — 실재성(實在性)
보기 좋은 것보다 **실제로 작동하고, 실제로 가치를 주는 것**을 만든다.
감이 아니라 데이터로 검증하고, 부풀리지 않는다. (자소서·전략·제품 모두 이 기준.)

## 세 자산
| 자산 | 무엇 | 근거 |
| --- | --- | --- |
| **AI / 빌딩** | LLM·멀티에이전트·풀스택 앱을 직접 설계·출시 | Neural Flow, 무신사 AI 광고제 |
| **콘텐츠 / 영상** | 기획→연출→편집, 생성형 AI 결합, 트렌드를 바이럴로 | 나는샬롬, 청년부 영상팀 |
| **사용자 이해** | 질적 리서치로 진짜 문제를 구조화 | 유학생 멘토링, E-Nudge |

---

## 학습·경험 여정
- **미디어 기반 + 영상 연출:** 미디어커뮤니케이션 전공, 교회 청년부 영상팀장으로 기획·연출·편집 전 과정을 끌어옴.
- **AI를 '쓰는 것'에서 '만드는 것'으로:** 생성형 AI 영상·이미지 제작 → 기획·생성·셀렉을 나눈 멀티에이전트 파이프라인 설계 → LLM API 직결·OAuth·풀스택 앱 출시까지.
- **도메인 확장:** 도시계획·부동산 복수전공으로 공간·시장 데이터 분석 기반을 더함.
- **사용자·데이터:** 유학생 심층 인터뷰로 문제를 구조화해 멘토링을 재설계, 측정 가능한 결과로 검증.
- **현재:** AI 일정·관계 비서 *Neural Flow*를 혼자 기획·개발·출시하며, 콘텐츠·AI·사용자이해를 하나의 제품으로 수렴시키는 중.

## 대표 프로젝트
- **Neural Flow** — 자연어를 LLM이 2주 일정으로 분해·배치하고 캘린더·노션과 동기화하는 AI 비서. 데스크톱·모바일 풀스택을 단독으로 기획·개발·배포. *(빌딩·서비스기획)*
- **무신사 무진장 AI 광고제 『피드백샌드백』** — 퀄리티 정면승부 대신 '판을 바꿔', 멀티에이전트 파이프라인과 자동화 도구를 직접 만들어 적은 인원으로 완성. *(AI·전략·자동화)*
- **나는샬롬 (2부작)** — 연애 리얼리티 포맷을 빌려 만든 수련회 홍보 콘텐츠. 영상팀장으로 프리프로덕션~편집 전 과정 감독. *(콘텐츠·연출·PM)*
- **E-Nudge** — 이미지 데이터 + 행동 넛지 설계. *(데이터·행동설계)*
- **AdGuard** — 팀장·PM. *(리더십·프로젝트)*
- **Microsoft AI School — 회랑(기억의 궁전)** — AI 공간 스캐너·3D·인지 근거 설계. *(공간 × AI)*
