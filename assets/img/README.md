## 개인정보 처리

수료증 원본은 국문면·영문면이 함께 펼쳐진 사진이고, **국문면에 생년월일이
인쇄되어 있다.** 영문면에는 성명·과정명·수료일만 있고 생년월일이 없어,
`msai-cert.jpg`는 **영문면만 잘라 썼다.** 마스킹 없이도 생년월일이 노출되지
않는다. 국문면(훈련기간 표기)이 필요하면 해당 영역을 가린 뒤 교체할 것.
